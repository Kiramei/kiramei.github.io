This repository contains the source for [kiramei.cn](https://kiramei.cn), a personal site for research notes, open-source projects, and music-video production stories.

## Current focus

- Efficient Diffusion Transformer inference: [ChebBooster](https://github.com/Kiramei/ChebBooster) and [BaryCache](https://github.com/Kiramei/BaryCache)
- 3D human motion prediction: [CBFL](https://github.com/Kiramei/CBFL) and [DAFCN](https://github.com/Kiramei/DAFCN)
- Cross-platform BAAS tooling: [BAAS Tauri](https://github.com/Kiramei/baas-tauri)
- Reusable academic writing tools: [Kiramei Preprint Style](https://github.com/Kiramei/kiramei-preprint)
- Cover-song MV production and visual storytelling

## Stack

Astro, Svelte, TypeScript, Tailwind CSS, and GitHub Pages.
