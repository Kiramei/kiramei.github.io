**BAAS WebUI is now archived.** This is not the disappearance of the interface; it is the end of maintaining the same idea in two places. The WebUI has been folded into **BAAS Tauri**, where the frontend, desktop shell, updater, packaging, and documentation can evolve as one product.

## What BAAS WebUI established

The standalone React application rebuilt the Blue Archive Auto Script GUI as a modern control surface. It introduced the pieces that made BAAS feel less like a collection of commands and more like a daily workstation:

- multiple profiles for different accounts, servers, and emulator instances;
- a searchable, reorderable scheduler with task windows and overrides;
- real-time task status, assets, and log streams over authenticated WebSockets;
- detailed configuration panels for cafés, arenas, stages, shops, notifications, and more;
- themes, localization, update controls, and an embedded documentation experience.

That foundation remains. What changed is where it lives.

## Why merge it into Tauri?

A browser UI is excellent for rapid iteration, but a desktop automation client eventually needs desktop responsibilities: native windows, installers, update channels, filesystem integration, platform capabilities, and reliable coordination with a local backend. Keeping these in a separate shell while duplicating the frontend created unnecessary distance between releases.

BAAS Tauri now owns that complete boundary. **Tauri 2 and Rust** provide the native shell; **React, TypeScript, Vite, and Tailwind CSS** continue to power the interface. The backend remains responsible for ADB, screenshots, recognition, emulator control, and task execution, while the desktop client manages profiles, scheduling, configuration, logs, remote display, documentation, and updates.

## Where to go now

Existing references to BAAS WebUI remain available for history, but new issues, features, releases, and documentation belong in BAAS Tauri. Installers are published for Windows, macOS, and Linux, with separate packages for common CPU architectures.

- [BAAS Tauri repository](https://github.com/Kiramei/baas-tauri)
- [Latest releases](https://github.com/Kiramei/baas-tauri/releases/latest)
- [Archived BAAS WebUI repository](https://github.com/Kiramei/baas-webui)

Archiving the old repository closes one branch of the project tree. Merging it into BAAS Tauri lets the same work continue with a clearer home.
